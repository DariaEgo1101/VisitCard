# Сайт-визитка Дарьи Егоровой

## О проекте
Одностраничный адаптивный сайт-визитка графического дизайнера. Стек: HTML, CSS, JavaScript без внешних библиотек.

## Файлы
- `index.html` — структура страницы и контент.
- `style.css` — цвета, типографика, компоненты и адаптивная вёрстка.
- `script.js` — мобильная навигация и форма подготовки письма.
- `README.md` — описание проекта и документирование использования AI.

## Запуск
Откройте `index.html` в браузере. Для локальной разработки можно открыть папку в редакторе кода и запустить через любой локальный статический сервер.

## Адаптивность / Mobile First
Сначала написаны базовые стили для узкого экрана; затем через media queries добавлены варианты для планшетов (`min-width: 620px`) и настольных экранов (`min-width: 900px`). Вёрстка использует CSS Grid/Flexbox, относительные размеры и доступные состояния фокуса.

## JavaScript-функционал
1. Мобильное меню раскрывается по кнопке, обновляет `aria-expanded` и закрывается после выбора пункта.
2. Форма обратной связи проверяет обязательные поля и email, затем подготавливает письмо через `mailto:`. Данные не отправляются на сервер.

Перед публикацией замените `hello@example.com` на реальный адрес в `index.html` и `script.js`.

- **Инструмент:** ChatGPT (OpenAI).
- **Задача:** помощь с проектированием структуры, черновой реализацией HTML/CSS/JavaScript и проверочным списком.
- **Время выполнения:** 14 октября 2026 года.
- **Существенный запрос:** «Создай сайт-визитку графического дизайнера в мятной палитре; используй Mobile First, разделы обо мне, навыки, образование, проекты и контакты; добавь JavaScript-функционал и документируй его».
